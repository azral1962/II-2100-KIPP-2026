Discovery
Discovery menuju shared problem statement.
Kompetensi target
Mendengar sebelum proposing dan membangun shared problem statement dengan person.
Evidence wajib
Initial assumption dan pertanyaan discovery.
Paraphrase hasil percakapan serta problem impact dan constraint.
Konfirmasi langsung dari partner terhadap pemahaman masalah.
Shared problem statement yang sesuai dengan hasil discovery dan dikonfirmasi partner.
Konteks performance
Tanggal dan setting:
Sekitar masa perkuliahan, percakapan dilakukan secara langsung dengan teman sekelas ketika ia mengalami kesulitan dalam melakukan setup Visual Studio Code untuk keperluan perkuliahan.
Persons dan relationship:
Saya berbicara dengan teman sekelas yang sedang mengalami kendala dalam menggunakan Visual Studio Code.
Objective dan initial state:
Tujuan saya adalah memahami kesulitan yang dialami teman sebelum memberikan bantuan. Pada awalnya saya mengira masalahnya adalah teman saya tidak memahami coding yang sedang dikerjakan.
Evidence
Teman sekelas saya mengatakan bahwa ia mengalami kesulitan ketika menggunakan Visual Studio Code.
Initial assumption saya adalah bahwa ia tidak mengerti coding yang sedang dikerjakan. Sebelum langsung memberikan solusi, saya bertanya:
“Apa yang ga lu ngerti?”
Setelah mendengar penjelasannya, saya mengetahui bahwa masalah utamanya bukan pada pemahaman coding, tetapi pada proses setup Visual Studio Code yang belum berhasil dilakukan.
Saya kemudian mengonfirmasi kembali pemahaman saya secara langsung kepada teman. Teman membenarkan bahwa kendalanya memang berada pada proses setup Visual Studio Code.
Setelah masalah tersebut dipastikan, saya membantu melakukan setup Visual Studio Code sekaligus menjelaskan langkah-langkahnya agar teman saya dapat memahami prosesnya.
Problem impact: Teman saya belum dapat menggunakan Visual Studio Code dengan baik untuk melanjutkan kegiatan pemrograman karena proses setup belum berhasil.
Constraint: Teman saya membutuhkan bantuan dalam melakukan setup Visual Studio Code sebelum dapat melanjutkan kegiatan pemrograman.
Setelah dibantu, teman saya mengucapkan terima kasih.
Kontribusi saya adalah melakukan discovery melalui pertanyaan, mengonfirmasi masalah yang ditemukan, kemudian membantu menyelesaikan setup sambil menjelaskan prosesnya.
Shared problem statement
Berdasarkan hasil discovery dan konfirmasi langsung dengan teman, kami memahami bahwa masalah utamanya bukan karena teman saya tidak memahami coding, tetapi karena setup Visual Studio Code belum berhasil.
Teman saya membutuhkan bantuan untuk menyelesaikan setup Visual Studio Code agar dapat melanjutkan kegiatan pemrograman.
Problem statement tersebut dibangun berdasarkan hasil pertanyaan discovery dan telah dikonfirmasi secara langsung oleh teman.
Analisis komunikasi
Elemen
Evidence dan analisis
Person & character
Saya berbicara dengan teman sekelas sehingga menggunakan bahasa yang santai dan langsung. Saya juga berusaha memahami kendalanya sebelum memberikan bantuan.
Objective & state
Tujuan awalnya adalah mengetahui bagian yang menjadi kendala. Saya awalnya mengira masalahnya adalah coding, tetapi setelah bertanya ternyata masalahnya adalah setup Visual Studio Code.
Repertoire & language
Saya menggunakan pertanyaan sederhana, “Apa yang ga lu ngerti?”, untuk mengetahui bagian yang menjadi kendala. Setelah masalah ditemukan, saya menggunakan penjelasan langkah-langkah setup untuk membantu.
Response & adaptation
Saya mengubah asumsi awal setelah mendapatkan informasi dari teman. Awalnya saya mengira masalahnya adalah coding, tetapi kemudian menyesuaikan bantuan karena masalah sebenarnya adalah setup Visual Studio Code.
Agreement & action
Setelah mengetahui masalahnya dan mengonfirmasi pemahaman saya dengan teman, saya membantu melakukan setup Visual Studio Code sambil menjelaskan prosesnya.
Relationship outcome
Teman dapat memperoleh bantuan untuk melakukan setup dan memberikan respons positif berupa ucapan terima kasih. Interaksi tetap berjalan dengan baik.
Penggunaan AI
Tidak menggunakan AI saat percakapan berlangsung.
Discovery, konfirmasi masalah, dan bantuan dilakukan secara langsung dengan teman sekelas. Saya tidak menggunakan AI untuk menentukan masalah atau memberikan solusi dalam percakapan tersebut.
AI hanya digunakan setelah percakapan untuk membantu mengevaluasi dan merefleksikan proses discovery berdasarkan evidence yang saya tuliskan.
Feedback dan tindak lanjut
Feedback yang diterima:
Teman mengonfirmasi secara langsung bahwa masalah yang dialaminya memang berada pada setup Visual Studio Code, bukan pada pemahaman coding. Setelah saya membantu melakukan setup dan menjelaskan prosesnya, teman saya juga mengucapkan terima kasih.
Adaptation/replay:
Saya menyadari bahwa asumsi awal saya bahwa teman tidak memahami coding ternyata tidak tepat. Dengan bertanya dan mengonfirmasi kembali, saya dapat menyesuaikan bantuan dengan masalah yang sebenarnya.
Jika menghadapi situasi serupa, saya akan tetap melakukan konfirmasi sebelum memberikan solusi agar bantuan yang diberikan sesuai dengan kebutuhan partner.
Next practice:
Saya akan mempertahankan kebiasaan untuk tidak langsung memberikan solusi berdasarkan asumsi. Saya akan bertanya terlebih dahulu, memahami masalah, kemudian mengonfirmasi pemahaman saya sebelum memberikan bantuan.
Refleksi
Dari pengalaman ini, saya menyadari bahwa asumsi awal tidak selalu sesuai dengan masalah sebenarnya. Awalnya saya mengira teman mengalami kesulitan dalam memahami coding, tetapi setelah melakukan discovery melalui pertanyaan, saya mengetahui bahwa kendalanya berada pada setup Visual Studio Code.
Saya juga menyadari pentingnya melakukan konfirmasi terhadap pemahaman masalah. Konfirmasi langsung dengan teman membantu memastikan bahwa solusi yang saya berikan sesuai dengan masalah yang sebenarnya dialami.
Ke depannya, saya akan lebih membiasakan diri untuk mendengar dan memahami masalah terlebih dahulu sebelum langsung memberikan solusi.
