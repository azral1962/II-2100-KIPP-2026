Professional
Discovery
Discovery menuju shared problem statement.
Kompetensi target
Mendengar sebelum proposing dan membangun shared problem statement dengan person.
Evidence wajib
Initial assumption dan pertanyaan discovery.
Paraphrase hasil percakapan serta problem impact dan constraint.
Konfirmasi langsung dari partner terhadap pemahaman masalah.
Shared problem statement yang sesuai dengan hasil discovery dan dikonfirmasi partner.
Konteks performance
Tanggal dan setting:
Sekitar masa perkuliahan, percakapan dilakukan secara langsung dengan teman sekelas ketika ia mengalami kesulitan dalam melakukan setup Visual Studio Code untuk keperluan perkuliahan.
Persons dan relationship:
Saya berbicara dengan teman sekelas yang sedang mengalami kendala dalam menggunakan Visual Studio Code.
Objective dan initial state:
Tujuan saya adalah memahami kesulitan yang dialami teman sebelum memberikan bantuan. Pada awalnya saya mengira masalahnya adalah teman saya tidak memahami coding yang sedang dikerjakan.
Evidence
Teman sekelas saya mengatakan bahwa ia mengalami kesulitan ketika menggunakan Visual Studio Code.
Initial assumption saya adalah bahwa ia tidak mengerti coding yang sedang dikerjakan. Sebelum langsung memberikan solusi, saya bertanya:
“Apa yang ga lu ngerti?”
Setelah mendengar penjelasannya, saya mengetahui bahwa masalah utamanya bukan pada pemahaman coding, melainkan pada proses setup Visual Studio Code yang belum berhasil dilakukan.
Sebelum masuk ke langkah-langkah teknis maupun memberikan solusi, saya melakukan paraphrasing dan mengonfirmasi Shared Problem Statement secara eksplisit kepada teman:
Saya: “Oh, jadi intinya masalahnya adalah di setup VS Code, bukan karena lu ga ngerti coding-nya, benar?”
Teman: “Iya, bener banget. Coding-nya sih paham, tapi ini VS Code-nya ga mau jalan pas di-setup.”
Setelah partner mengonfirmasi dan menyepakati masalah tersebut secara eksplisit, barulah saya mulai memberikan solusi dengan membantu melakukan setup Visual Studio Code sekaligus menjelaskan langkah-langkahnya agar teman saya dapat memahami prosesnya.
Problem impact: Teman saya belum dapat menggunakan Visual Studio Code dengan baik untuk melanjutkan kegiatan pemrograman karena proses setup belum berhasil.
Constraint: Teman saya membutuhkan bantuan dalam melakukan setup Visual Studio Code sebelum dapat melanjutkan kegiatan pemrograman.
Setelah dibantu, teman saya mengucapkan terima kasih.
Kontribusi saya adalah melakukan discovery melalui pertanyaan, menyampaikan paraphrase untuk konfirmasi masalah (Shared Problem Statement) sebelum solusi, lalu membantu menyelesaikan setup sambil menjelaskan prosesnya.
Shared problem statement
Berdasarkan hasil discovery dan konfirmasi eksplisit dari percakapan dengan teman, kami menyepakati bahwa masalah utamanya bukan karena pemahaman coding, melainkan kegagalan pada proses setup lingkungan kerja di editor.
Shared Problem Statement: “Teman saya membutuhkan bantuan untuk menyelesaikan setup Visual Studio Code agar dapat melanjutkan kegiatan pemrograman.”
Problem statement tersebut dibangun dari hasil discovery dan telah dikonfirmasi serta disepakati oleh partner sebelum solusi teknis dieksekusi.
Analisis komunikasi
Elemen
Evidence dan analisis
Person & character
Saya berbicara dengan teman sekelas sehingga menggunakan bahasa yang santai dan langsung. Saya juga berusaha memahami kendalanya sebelum memberikan bantuan.
Objective & state
Tujuan awalnya adalah mengetahui bagian yang menjadi kendala. Saya awalnya mengira masalahnya adalah coding, tetapi setelah bertanya ternyata masalahnya adalah setup Visual Studio Code.
Repertoire & language
Saya menggunakan pertanyaan sederhana (“Apa yang ga lu ngerti?”) untuk menggali masalah, lalu mengonfirmasi pemahaman secara eksplisit (“Jadi intinya masalahnya di setup VS Code, bukan coding, benar?”) sebelum memberikan penjelasan teknis setup.
Response & adaptation
Saya mengubah asumsi awal setelah mendapatkan informasi dari teman. Awalnya saya mengira masalahnya adalah coding, tetapi kemudian menyesuaikan bantuan dari penjelasan coding menjadi bantuan setup VS Code.
Agreement & action
Setelah partner mengonfirmasi eksplisit masalah utamanya, saya memberikan solusi bantuan setup VS Code sambil menjelaskan prosesnya.
Relationship outcome
Teman dapat memperoleh bantuan untuk melakukan setup dan memberikan respons positif berupa ucapan terima kasih. Interaksi tetap berjalan dengan baik.
Penggunaan AI
Tidak menggunakan AI saat percakapan berlangsung.
Discovery, konfirmasi masalah, dan bantuan dilakukan secara langsung dengan teman sekelas. Saya tidak menggunakan AI untuk menentukan masalah atau memberikan solusi dalam percakapan tersebut.
AI hanya digunakan setelah percakapan untuk membantu mengevaluasi dan merefleksikan proses discovery berdasarkan evidence yang saya tuliskan.
Feedback dan tindak lanjut
Feedback yang diterima:
Teman mengonfirmasi secara eksplisit bahwa masalah yang dialaminya memang berada pada setup Visual Studio Code, bukan pada pemahaman coding. Setelah saya membantu melakukan setup dan menjelaskan prosesnya, teman saya juga mengucapkan terima kasih.
Adaptation/replay:
Saya menyadari bahwa asumsi awal saya bahwa teman tidak memahami coding ternyata tidak tepat. Dengan menyampaikan paraphrase konfirmasi eksplisit (“Jadi intinya masalahnya di setup VS Code, bukan coding, benar?”) sebelum melangkah ke solusi, saya memastikan bahwa kami telah menyepakati Shared Problem Statement terlebih dahulu.
Next practice:
Saya akan mempertahankan kebiasaan untuk tidak langsung memberikan solusi berdasarkan asumsi. Saya akan mengajukan pertanyaan discovery, mengonfirmasi Shared Problem Statement secara eksplisit dengan partner, dan baru memberikan solusi teknis setelah ada persetujuan.
Refleksi
Dari pengalaman ini, saya menyadari bahwa asumsi awal tidak selalu sesuai dengan masalah sebenarnya. Awalnya saya mengira teman mengalami kesulitan dalam memahami coding, tetapi setelah melakukan discovery melalui pertanyaan, saya mengetahui bahwa kendalanya berada pada setup Visual Studio Code.
Saya juga menyadari pentingnya melakukan konfirmasi eksplisit terhadap pemahaman masalah sebelum memberikan solusi. Konfirmasi langsung dengan partner memastikan bahwa solusi yang saya berikan benar-benar tepat sasaran dan disepakati bersama.
Ke depannya, saya akan lebih membiasakan diri untuk mendengar, mengonfirmasi masalah secara eksplisit, baru kemudian melangkah ke pemberian solusi.
