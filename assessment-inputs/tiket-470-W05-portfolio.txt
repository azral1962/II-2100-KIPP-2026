Kompetensi target
Mendengar sebelum proposing dan membangun shared problem statement dengan person.

Initial assumption dan pertanyaan discovery.

Shared problem statement yang dikonfirmasi partner.
Konteks performance
Tanggal dan setting:
Sekitar masa perkuliahan, percakapan dilakukan secara langsung dengan teman sekelas ketika ia mengalami kesulitan dalam melakukan setup Visual Studio Code untuk keperluan perkuliahan.
Persons dan relationship:
Saya berbicara dengan teman sekelas yang sedang mengalami kendala dalam menggunakan Visual Studio Code.
Objective dan initial state:
Tujuan saya adalah memahami kesulitan yang dialami teman sebelum memberikan bantuan. Pada awalnya saya mengira masalahnya adalah teman saya tidak memahami coding yang sedang dikerjakan.
Evidence
Teman sekelas saya mengatakan bahwa ia mengalami kesulitan ketika menggunakan Visual Studio Code.
Initial assumption saya adalah bahwa ia tidak mengerti coding yang sedang dikerjakan. Sebelum langsung memberikan solusi, saya bertanya:
“Apa yang ga lu ngerti?”
Setelah mendengar jawabannya, saya mengetahui bahwa masalah utamanya bukan pada pemahaman coding, tetapi pada setup Visual Studio Code yang belum berhasil dilakukan.
Setelah mengetahui masalah tersebut, saya membantu melakukan setup Visual Studio Code sekaligus menjelaskan langkah-langkahnya agar teman saya dapat memahami prosesnya.
Setelah dibantu, teman saya mengucapkan terima kasih.
Kontribusi saya adalah melakukan discovery melalui pertanyaan terlebih dahulu, kemudian membantu menyelesaikan masalah setup sambil menjelaskan prosesnya.
Shared problem statement
Teman saya membutuhkan bantuan dalam melakukan setup Visual Studio Code agar dapat mulai menggunakan lingkungan pemrograman yang diperlukan untuk perkuliahan.
Problem statement ini terbentuk setelah saya menanyakan bagian yang tidak dipahami dan mengetahui bahwa kendalanya berada pada proses setup, bukan pada pemahaman coding.
Analisis komunikasi
Elemen
Evidence dan analisis
Person & character
Saya berbicara dengan teman sekelas sehingga menggunakan bahasa yang santai dan langsung. Saya juga berusaha memahami kendalanya sebelum memberikan bantuan.
Objective & state
Tujuan awalnya adalah mengetahui bagian yang membuat teman kesulitan. Saya awalnya mengira masalahnya adalah coding, tetapi setelah bertanya ternyata masalahnya adalah setup Visual Studio Code.
Repertoire & language
Saya menggunakan pertanyaan sederhana, yaitu “Apa yang ga lu ngerti?” untuk mengetahui bagian yang menjadi kendala. Setelah masalah ditemukan, saya menggunakan penjelasan langkah-langkah setup untuk membantu.
Response & adaptation
Saya mengubah asumsi awal setelah mendapatkan informasi dari teman. Awalnya saya mengira masalahnya adalah coding, tetapi kemudian menyesuaikan bantuan karena masalah sebenarnya adalah setup Visual Studio Code.
Agreement/action
Setelah mengetahui masalahnya, saya membantu melakukan setup Visual Studio Code sambil menjelaskan prosesnya kepada teman.
Relationship outcome
Teman dapat memperoleh bantuan untuk melakukan setup dan memberikan respons berupa ucapan terima kasih. Interaksi tetap berjalan dengan baik.
Penggunaan AI
Tidak menggunakan AI.
Discovery dan bantuan dilakukan secara langsung dengan teman sekelas. Saya tidak menggunakan AI untuk menentukan masalah atau memberikan solusi dalam percakapan tersebut.
Feedback dan tindak lanjut
Feedback yang diterima:
Teman saya mengucapkan terima kasih setelah saya membantu melakukan setup Visual Studio Code dan menjelaskan prosesnya.
Adaptation/replay:
Saya menyadari bahwa asumsi awal saya mengenai masalah coding tidak langsung benar. Dengan bertanya terlebih dahulu, saya dapat mengetahui bahwa masalah sebenarnya berada pada setup Visual Studio Code. Jika menghadapi situasi serupa, saya akan mempertahankan kebiasaan untuk bertanya sebelum memberikan solusi.
Next practice:
Saya akan lebih sering mengajukan pertanyaan untuk memahami masalah sebenarnya sebelum langsung memberikan solusi.
