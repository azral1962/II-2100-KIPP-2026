Hasil Pengerjaan: Portofolio Terjemahan 5 Bahasa (Rulyansyah Fajar Ramadhan - 18225025)
1. Core Meaning (Pesan Inti)
Pesan Inti: “Pengembangan fitur aplikasi kolaborasi ini sempat mengalami kendala teknis penundaan jadwal karena modul integrasi API butuh perbaikan logika, tetapi saat ini masalahnya sudah teratasi dan tim kembali fokus mengejar target rilis akhir minggu ini.”
2. Terjemahan untuk Lima Target Audiens Berbeda
Target Person / Character
Bahasa & Repertoire yang Digunakan
Hasil Terjemahan Pesan
1. Friend (Sahabat/Kakak)
Kasual, santai, penuh keakraban, fokus pada curhat kondisi beban kerja.
“Eh, proyek aplikasi kelompokku kemarin sempat keteteran gara-gara API-nya error. Tapi santai, sekarang kodenya udah beres dan kita lagi ngebut buat kelarin semuanya minggu ini.”
2. Technical Peer (Rekan Setim / Programer)
Teknis, langsung pada inti masalah (to the point), menggunakan istilah arsitektur sistem.
“Modul integrasi API mengalami bottleneck pada logika payload sebelumnya, namun sekarang bug tersebut sudah di-fix dan kita melanjutkan merge branch untuk target rilis akhir pekan.”
3. Manager (Dosen / Asisten / Project Lead)
Profesional, terstruktur, transparan, berorientasi pada solusi dan progres.
“Melaporkan progres pengerjaan proyek: sempat terjadi kendala teknis pada modul API yang berdampak pada penyesuaian linimasa. Saat ini kendala telah diselesaikan dan tim kembali on-track untuk target penyelesaian akhir minggu.”
4. Customer (Pengguna / Klien Fiktif)
Empatik, menenangkan, minim istilah teknis yang membingungkan, fokus pada kenyamanan pengguna.
“Halo! Mohon maaf atas sedikit keterlambatan pembaruan fitur kami. Tim kami sedang memastikan sistem berjalan jauh lebih stabil dan aman, dan pembaruan akan segera dapat Anda nikmati minggu ini.”
5. Public (Masyarakat Luas / Komunitas Publik)
Formal, edukatif, informatif, dan transparan secara umum.
“Dalam proses pengembangan sistem digital, pembaruan performa dan peningkatan kestabilan integrasi data terus dilakukan demi menghadirkan pengalaman layanan yang optimal bagi seluruh pengguna.”
3. Alasan Perubahan Language dan Repertoire
Friend: Menggunakan bahasa lisan yang santai untuk mencairkan ketegangan emosional tanpa menuntut respons formal.
Technical Peer: Menggunakan istilah teknis yang spesifik agar efisien dan langsung dipahami oleh sesama pengembang.
Manager: Mengutamakan struktur pelaporan yang jelas, mencakup identifikasi masalah dan langkah mitigasinya secara profesional.
Customer: Mengalihkan fokus dari masalah internal kode ke kepuasan dan kenyamanan pengguna akhir.
Public: Menyampaikan informasi dalam bentuk pernyataan publik yang netral, informatif, dan menjaga reputasi profesional.
4. Feedback Understanding
Target yang Memberikan Umpan Balik: Rekan setim (Technical Peer) dan Kakak (Friend).
Hasil Feedback: Pesan inti berhasil diterima dengan jelas oleh kedua belah pihak tanpa ada distorsi informasi, di mana rekan teknis memahami detail perbaikan API, sementara pihak keluarga memahami situasi kondisi pengerjaan tugas tanpa merasa khawatir berlebihan.
