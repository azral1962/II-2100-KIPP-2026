Saya memilih Ketua Kelas / Koordinator Mata Kuliah sebagai target utama karena memiliki pengalaman langsung dalam mencatat keterlambatan pengumpulan draf dan dapat menjembatani usulan perbaikan alur ke seluruh angkatan.
Attention pitch
“Dari pemantauan dua minggu terakhir, 4 dari 6 kelompok kelas kita mengalami keterlambatan pengunggahan draf tugas karena alur integrasi file di obrolan grup terpisah-pisah. Akibatnya, ada 3 kali pengiriman file versi lama yang tidak sengaja terunggah ke portal. Saya belum mengusulkan penggantian platform, tetapi bolehkah kita memeriksa apakah masalah utamanya ada pada kejelasan batasan revisi dan penamaan file?”
Data yang digunakan: Catatan waktu unggah draf dari 6 kelompok dan rekapitulasi kesalahan versi file di grup obrolan angkatan.
Response dan state assessment
Ketua kelas merespons: “Masalah bentrok versi file memang sering terjadi, tapi biasanya karena mahasiswa baru pengerjaannya mendekati jam tenggat. Apakah penyeragaman nama file benar-benar bisa menyelesaikan masalah itu?”
Respons ini menunjukkan target menyadari adanya masalah, namun meragukan efektivitas penyeragaman format sebagai solusi utama. State target bergeser dari Problem aware menjadi Attention dengan reservasi.
Adaptasi komunikasi: > “Sangat setuju, faktor pengerjaan di akhir waktu memang berpengaruh. Bisakah kita mencoba menerapkan aturan format penamaan file sederhana di 2 kelompok dulu minggu ini untuk melihat apakah tingkat kesalahan unggah file berkurang?”
Ketua kelas menyetujui uji coba (pilot test) terbatas pada 2 kelompok untuk tugas minggu depan.
Evidence dan refleksi
Bukti target map sebelum dan sesudah wawancara pitching.
Tangkapan layar kesepakatan uji coba format penamaan file bersama Ketua Kelas lewat obrolan WhatsApp.
Kesepakatan: Penilaian keberhasilan uji coba didasarkan pada ketepatan versi file yang dikirimkan pada tugas berikutnya.
Penggunaan AI: AI digunakan untuk menyederhanakan struktur attention pitch agar dapat disampaikan di bawah 40 detik tanpa menambah data fiktif.
