Tujuan Pembelajaran
Latihan ini digunakan untuk melatih kejernihan batin (intrapersonal communication) dengan memisahkan fakta objektif dari interpretasi, mengenali emosi, melihat satu peristiwa melalui tiga narasi, serta memilih respons yang disengaja.
Alur refleksi yang saya gunakan adalah:
Peristiwa/Fakta → Interpretasi → Emosi → Narasi → Pilihan → Tindakan → Evaluasi
Hal penting yang saya pelajari dari latihan ini adalah bahwa fakta, interpretasi, emosi, dan tindakan merupakan hal yang berbeda. Emosi saya valid untuk diakui, tetapi emosi tidak otomatis membuktikan bahwa interpretasi saya benar.
Bagian 1 — Identifikasi Kasus
1. Peristiwa yang Dapat Diamati (Fakta Objektif)
Peristiwa yang saya gunakan berasal dari pengalaman mengerjakan tugas besar secara berkelompok. Pada periode tersebut, kelompok menghadapi beberapa tuntutan akademik secara bersamaan, termasuk UTS dan deadline Milestone 2.
Dalam percakapan kelompok, saya mengingatkan anggota kelompok agar mulai mengerjakan lebih awal karena jadwal akan semakin padat.
Pada tahap berikutnya, kelompok membahas pembagian pekerjaan. Saya ikut melakukan koordinasi, menyatakan bahwa saya mengambil bagian Bab 2, dan mengingatkan agar pekerjaan segera dimulai sehingga masih tersedia waktu untuk asistensi dan revisi.
Dalam proses pengerjaan teknis, saya juga menyatakan bahwa saya mengerjakan bagian coding KWN dan meminta anggota lain menangani bagian video Odoo.
Fakta yang benar-benar dapat diamati
Kelompok memiliki tugas besar dengan deadline Milestone 2.
Pada periode tersebut terdapat tuntutan akademik lain, termasuk UTS.
Saya mengingatkan kelompok untuk mulai mengerjakan lebih awal.
Saya ikut membahas pembagian pekerjaan.
Saya mengambil bagian Bab 2.
Saya mengingatkan kelompok agar pekerjaan selesai lebih awal sehingga masih ada waktu untuk asistensi dan revisi.
Saya mengerjakan bagian coding KWN.
Saya meminta anggota lain menangani bagian video Odoo.
Saya melakukan komunikasi dan koordinasi mengenai pembagian pekerjaan.
Batas antara fakta dan interpretasi
Dari fakta tersebut, saya tidak dapat menyimpulkan bahwa anggota lain malas, tidak bertanggung jawab, tidak peduli terhadap tugas, atau pasti tidak akan menyelesaikan bagiannya.
Yang dapat saya simpulkan dari fakta hanyalah bahwa:
Kelompok sedang berada dalam situasi dengan tuntutan waktu yang tinggi dan membutuhkan koordinasi pembagian pekerjaan.
Hal mengenai niat, kemampuan, atau tingkat usaha anggota lain merupakan informasi yang tidak dapat saya pastikan hanya dari situasi tersebut.
2. Interpretasi Pertama / Asumsi Otomatis
Interpretasi pertama saya ketika melihat deadline semakin dekat adalah:
“Saya harus memastikan pekerjaan kelompok tetap berjalan karena kalau saya tidak ikut mengingatkan atau mengambil tindakan, ada kemungkinan pekerjaan tidak selesai tepat waktu.”
Saya juga cenderung berpikir bahwa mengambil lebih banyak tanggung jawab akan membuat situasi menjadi lebih aman.
Pada saat itu, saya tidak secara sadar membedakan antara:
fakta bahwa deadline memang semakin dekat;
kekhawatiran saya bahwa pekerjaan mungkin terlambat;
asumsi bahwa saya harus mengambil lebih banyak pekerjaan agar tugas berhasil.
Setelah melakukan refleksi, saya menyadari bahwa ketiganya berbeda.

Sensasi tubuh
Ketika memikirkan deadline dan banyaknya pekerjaan yang harus diselesaikan, saya merasa tubuh lebih tegang dan sulit merasa benar-benar tenang sebelum melihat adanya perkembangan pekerjaan.
Saya juga merasakan dorongan untuk segera melakukan sesuatu agar situasi terasa lebih terkendali. Dorongan tersebut muncul dalam bentuk mengingatkan anggota kelompok, ikut mengatur pembagian pekerjaan, mengambil bagian tugas, dan menawarkan bantuan.
Makna emosi bagi saya
Setelah melakukan refleksi, saya melihat bahwa kecemasan tersebut tidak harus dipandang sebagai sesuatu yang salah.

Emosi dapat menjadi informasi mengenai apa yang penting bagi saya, tetapi emosi bukan bukti bahwa interpretasi saya benar.

saya boleh merasa cemas;

saya tetap perlu memeriksa fakta sebelum menentukan tindakan.
Bagian 2 — Membedah Tiga Narasi
Versi A — Narasi Korban (Victim Narrative)
Isi Narasi Korban
Jika saya melihat situasi melalui narasi korban, saya dapat berpikir bahwa keberhasilan tugas terlalu bergantung pada anggota lain.
Saya dapat merasa bahwa saya sudah menjalankan tanggung jawab saya, tetapi saya tidak dapat memastikan tugas selesai karena saya bergantung pada tindakan orang lain.
Dari sudut pandang ini, saya merasa pilihan saya terbatas. Saya merasa harus terus mengingatkan anggota kelompok atau mengambil lebih banyak pekerjaan sendiri agar tugas tetap berjalan.
Pikiran yang muncul dapat berbentuk:
“Kalau saya tidak ikut turun tangan, nanti tugasnya tidak selesai.”
“Saya harus memastikan semuanya berjalan.”
“Lebih aman kalau saya ambil bagian tambahan daripada menunggu.”
Dalam narasi ini, sebagian besar kendali saya terasa berada di luar diri saya.
Tindakan Reaktif yang Mungkin Muncul
Jika saya sepenuhnya mengikuti narasi korban, saya cenderung:
mengambil terlalu banyak pekerjaan;
terus mengingatkan anggota kelompok;
merasa kesal ketika pekerjaan belum terlihat selesai;
sulit mempercayai anggota lain untuk menyelesaikan bagiannya;
mengambil alih pekerjaan ketika deadline terasa semakin dekat.
Tindakan tersebut memang dapat memberikan rasa aman sementara karena saya merasa memiliki kendali.
Namun, konsekuensinya dapat berupa:
beban kerja saya menjadi terlalu besar;
anggota lain kehilangan ruang untuk bertanggung jawab;
saya menjadi semakin tertekan;
hubungan kerja kelompok dapat menjadi kurang seimbang.
Versi B — Narasi Analitis (Analytical Narrative)
1. Apa yang benar-benar telah terbukti?
Fakta yang benar-benar saya ketahui adalah:
Kelompok memiliki tugas besar dengan deadline Milestone 2.
Pada periode tersebut terdapat UTS dan tuntutan akademik lain.
Kelompok perlu membagi pekerjaan.
Saya mengambil bagian Bab 2.
Saya mengingatkan kelompok agar mulai mengerjakan lebih awal.
Saya mengingatkan bahwa pekerjaan perlu selesai lebih awal agar tersedia waktu untuk asistensi dan revisi.
Saya mengerjakan bagian coding KWN.
Saya meminta anggota lain menangani bagian video Odoo.
Saya melakukan koordinasi mengenai pekerjaan kelompok.
Sementara itu, beberapa hal belum terbukti, yaitu:
anggota lain pasti tidak bertanggung jawab;
anggota lain tidak akan bekerja apabila saya tidak mengingatkan;
tugas pasti akan terlambat jika saya tidak mengambil pekerjaan tambahan;
saya harus mengambil alih pekerjaan agar kelompok berhasil.
2. Penjelasan Alternatif yang Masuk Akal
Alternatif 1 — Masalahnya mungkin koordinasi, bukan ketidakmampuan
Anggota kelompok mungkin sebenarnya mampu menyelesaikan tanggung jawab masing-masing, tetapi membutuhkan pembagian pekerjaan dan komunikasi yang lebih jelas.
Jika ini benar, solusi yang tepat bukan mengambil alih pekerjaan mereka, melainkan memperjelas pembagian dan progres.
Alternatif 2 — Pekerjaan yang belum terlihat bukan berarti tidak dikerjakan
Saya tidak selalu dapat mengetahui progres anggota lain hanya dari apa yang terlihat di grup.
Pekerjaan yang belum menunjukkan hasil akhir dapat berarti:
masih dalam proses;
sedang dikerjakan di luar waktu komunikasi grup;
masih dalam tahap penyelesaian;
atau memang belum dikerjakan.
Saya perlu bertanya sebelum menyimpulkan.
Alternatif 3 — Kecemasan saya sendiri dapat memperbesar rasa urgensi
Dorongan saya untuk mengambil lebih banyak pekerjaan dapat berasal dari kekhawatiran saya terhadap deadline.
Artinya, rasa “harus segera turun tangan” dapat muncul sebelum masalah yang saya khawatirkan benar-benar terjadi.
Kesimpulan analitis
Dari tiga alternatif tersebut, saya menyadari:
Kekhawatiran bahwa tugas akan terlambat bukanlah fakta bahwa tugas pasti akan terlambat.
Karena itu, respons yang lebih tepat adalah memeriksa kondisi, berkomunikasi, lalu bertindak berdasarkan informasi, bukan langsung bertindak berdasarkan kekhawatiran.
3. Faktor yang Berada di Bawah Kendali Saya
Berada dalam kendali saya
cara saya menyampaikan kekhawatiran;
cara saya mengatur emosi;
bagian tugas yang saya ambil;
cara saya meminta update;
cara saya menawarkan bantuan;
cara saya mengatur waktu;
cara saya berkoordinasi;
keputusan untuk membantu tanpa mengambil alih;
keputusan untuk memeriksa fakta sebelum bereaksi;
keputusan untuk membuat batas waktu internal.
Tidak berada dalam kendali saya
seberapa cepat anggota lain bekerja;
bagaimana anggota lain mengatur waktunya;
keputusan pribadi anggota lain;
bagaimana anggota lain merespons pesan saya;
apakah anggota lain mengalami kendala yang tidak saya ketahui.
Pemisahan ini membantu saya memahami bahwa:
Tanggung jawab saya adalah mengelola kontribusi dan komunikasi saya, bukan mengendalikan perilaku seluruh anggota kelompok.
Versi C — Narasi Pertumbuhan (Growth Narrative)
Saya menyadari bahwa rasa cemas dan khawatir terhadap deadline muncul karena saya peduli terhadap hasil kerja kelompok dan ingin memastikan tanggung jawab saya dapat diselesaikan dengan baik.
Kepedulian tersebut merupakan hal yang ingin saya pertahankan.
Namun, saya belajar bahwa:
Bertanggung jawab tidak berarti harus mengendalikan seluruh pekerjaan kelompok.
Dalam pengalaman tersebut, saya sebenarnya sudah melakukan beberapa tindakan konkret:
mengingatkan kelompok mengenai deadline;
mengajak kelompok mulai mengerjakan lebih awal;
ikut membagi pekerjaan;
mengambil Bab 2;
mengerjakan coding KWN;
meminta anggota lain menangani bagian video Odoo.
Jadi, saya tidak hanya memiliki rencana untuk bertindak. Saya memang sudah melakukan tindakan koordinasi dan pembagian pekerjaan dalam situasi tersebut.
Yang perlu saya perbaiki bukan kepedulian atau kemauan untuk bertindak, tetapi cara memastikan bahwa tindakan saya tetap proporsional dan tidak berubah menjadi pengambilalihan tanggung jawab orang lain.
Pelajaran yang Saya Ambil
Pelajaran utama saya adalah:
Saya dapat bertanggung jawab terhadap bagian saya tanpa harus merasa bertanggung jawab atas seluruh pekerjaan orang lain.
Saya juga belajar bahwa tindakan cepat tidak selalu sama dengan respons yang tepat.
Respons yang lebih matang adalah:
berhenti sejenak → memeriksa fakta → memahami kondisi → menentukan tindakan yang berada dalam kendali saya.
Nilai yang Ingin Saya Pertahankan
Nilai yang ingin saya pertahankan:
tanggung jawab;
kerja sama;
komunikasi terbuka;
kepedulian terhadap kualitas pekerjaan;
kepercayaan terhadap anggota kelompok.
Saya tetap ingin menjadi anggota kelompok yang aktif dan dapat diandalkan, tetapi tidak ingin menjadikan kecemasan sebagai alasan untuk mengambil alih tanggung jawab orang lain.
Bagian 3 — Respons yang Dipilih
1. Tindakan yang Sudah Saya Lakukan dalam Peristiwa
Berdasarkan evidence yang tersedia, saya sudah melakukan beberapa tindakan nyata dalam situasi tersebut.
Tindakan 1 — Mengantisipasi deadline
Saya mengingatkan kelompok untuk mulai bekerja lebih awal karena adanya UTS dan deadline Milestone 2.
Tindakan 2 — Berpartisipasi dalam pembagian tugas
Saya ikut membahas pembagian pekerjaan dan mengambil bagian Bab 2.
Tindakan 3 — Mengomunikasikan kebutuhan waktu untuk revisi
Saya mengingatkan agar pekerjaan tidak dikerjakan terlalu dekat dengan deadline sehingga masih tersedia waktu untuk asistensi dan revisi.
Tindakan 4 — Mengambil tanggung jawab konkret
Saya mengerjakan bagian coding KWN.
Tindakan 5 — Membagi pekerjaan dengan anggota lain
Saya meminta anggota lain menangani bagian video Odoo ketika saya mengerjakan bagian coding.
Kesimpulan dari tindakan yang telah dilakukan
Dengan demikian, evidence yang tersedia menunjukkan bahwa saya sudah melakukan tindakan konkret, bukan hanya membuat rencana.
Tindakan tersebut terutama berbentuk:
mengomunikasikan risiko deadline → mengambil bagian pekerjaan → membagi tanggung jawab → mengoordinasikan pekerjaan.
Hal yang masih perlu saya kembangkan adalah memastikan bahwa tindakan tersebut tetap dilakukan berdasarkan kondisi nyata, bukan semata-mata karena rasa cemas.
2. Respons yang Lebih Baik untuk Situasi Serupa
Dari pengalaman tersebut, saya menyusun pola respons yang lebih disengaja:
Memastikan pembagian tugas sudah jelas.
Meminta update singkat dari setiap anggota.
Jika ada bagian yang belum selesai, menanyakan kendalanya terlebih dahulu.
Menawarkan bantuan jika memang diperlukan.
Mengambil pekerjaan tambahan hanya jika ada kebutuhan yang jelas dan telah disepakati.
Membuat batas waktu internal.
Menyisakan waktu untuk asistensi dan revisi.
Setelah itu mengevaluasi apakah bantuan saya memang diperlukan atau justru mengambil alih tanggung jawab anggota lain.
Contoh komunikasi asertif:
“Ges, biar aman sebelum deadline kita update progres masing-masing ya. Kalau ada bagian yang masih stuck atau butuh dibantu, kabarin aja. Kita coba beresin sesuai bagian masing-masing supaya masih ada waktu buat asistensi dan revisi.”
Respons ini lebih baik karena saya tidak langsung berasumsi bahwa orang lain tidak bekerja.
Saya terlebih dahulu:
memeriksa kondisi → menanyakan kebutuhan → menawarkan bantuan → menyepakati tindakan.
3. Dukungan dari Rekan
Nama rekan/pendamping: Suci
Saya memilih Suci sebagai rekan yang dapat memberikan perspektif dari luar mengenai cara saya berkomunikasi ketika menghadapi tekanan tugas kelompok.
Pertanyaan yang saya gunakan untuk mengevaluasi diri adalah:
“Menurut kamu, waktu ngerjain tugas kelompok kemarin aku terlalu banyak mengambil alih atau pembagian tugasnya masih cukup seimbang?”
Feedback tersebut penting karena saya ingin membedakan antara:
membantu kelompok
dan
mengambil alih tanggung jawab anggota lain.

mengomunikasikan pekerjaan yang sedang saya lakukan;
meminta anggota lain menangani bagian yang berbeda;
menggunakan pembagian tugas sebagai cara menghadapi beban pekerjaan.
Hal ini penting karena menunjukkan bahwa saya tidak hanya merencanakan pembagian tanggung jawab, tetapi benar-benar melaksanakannya dalam komunikasi kelompok.

Perubahan yang saya sadari
Sebelumnya saya cenderung menyamakan:
“Saya peduli terhadap hasil”
dengan:
“Saya harus memastikan semua hal berjalan.”
Sekarang saya memahami bahwa keduanya berbeda.
Saya tetap dapat peduli terhadap hasil kelompok tanpa mengambil alih seluruh proses.
Feedback dan Tindak Lanjut
Saya menggunakan Suci sebagai rekan untuk memberikan perspektif dari luar terhadap cara saya berkomunikasi dalam situasi kerja kelompok.
Pertanyaan yang ingin saya gunakan adalah:
“Menurut kamu, waktu ngerjain tugas kelompok kemarin aku terlalu banyak mengambil alih atau pembagian tugasnya masih cukup seimbang?”
Hal yang ingin saya evaluasi melalui pertanyaan tersebut adalah apakah tindakan saya masih berada pada batas:
bertanggung jawab dan membantu
atau sudah berubah menjadi:
mengambil alih tanggung jawab orang lain.
Untuk situasi berikutnya, pola tindak lanjut yang akan saya gunakan adalah:
cek fakta → tanyakan kondisi → pahami kebutuhan → tentukan bantuan → sepakati tindakan → evaluasi kembali.
Pola tersebut membantu saya mengubah kecenderungan:
cemas → langsung bertindak
menjadi:
cemas → berhenti → cek fakta → komunikasi → memilih tindakan.
Penggunaan AI
Saya menggunakan AI sebagai alat bantu untuk:
menyusun struktur refleksi;
memperjelas perbedaan antara fakta dan interpretasi;
mengidentifikasi apakah tiga narasi sudah dibedakan dengan jelas;
memeriksa apakah respons dan tindakan saya sudah sesuai dengan komponen LK 2;
memperjelas hubungan antara evidence dan refleksi.
Isi pengalaman, konteks tugas kelompok, emosi yang saya rasakan, tindakan yang saya lakukan, dan bukti percakapan berasal dari pengalaman saya sendiri.
AI tidak digunakan untuk membuat bukti percakapan atau mengubah kejadian agar terlihat berbeda dari keadaan sebenarnya.
Refleksi Akhir
Latihan ini membuat saya menyadari bahwa satu peristiwa dapat menghasilkan beberapa narasi yang berbeda.
Dalam narasi korban, saya melihat diri saya sebagai pihak yang harus menanggung beban karena keberhasilan tugas terasa bergantung pada anggota lain.
Dalam narasi analitis, saya dapat memisahkan fakta dari kekhawatiran. Saya menyadari bahwa deadline memang merupakan fakta, tetapi kekhawatiran bahwa tugas pasti terlambat atau anggota lain tidak bertanggung jawab merupakan interpretasi yang belum tentu benar.
Dalam narasi pertumbuhan, saya dapat melihat bahwa rasa khawatir terhadap deadline sebenarnya menunjukkan bahwa saya peduli terhadap tanggung jawab kelompok. Saya juga menyadari bahwa saya sudah melakukan tindakan konkret dalam situasi tersebut, seperti mengingatkan kelompok, ikut membagi tugas, mengambil Bab 2, mengerjakan coding KWN, dan meminta anggota lain menangani video Odoo.
Karena itu, area pertumbuhan saya bukan sekadar belajar untuk “bertindak”, tetapi belajar untuk bertindak secara proporsional dan berdasarkan fakta.
Pola yang ingin saya gunakan ketika menghadapi situasi serupa adalah:
Fakta → Interpretasi → Emosi → Pilihan → Tindakan → Evaluasi
Dengan pola tersebut, saya dapat tetap menjadi anggota kelompok yang aktif, bertanggung jawab, dan dapat diandalkan tanpa menjadikan kecemasan sebagai alasan untuk mengendalikan seluruh pekerjaan kelompok.
